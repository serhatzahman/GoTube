# GoTube Proxy Server

Nokia N9 (MeeGo 1.2 Harmattan) YouTube istemcisi için HTTP ve video akış köprüsü.

## Gereksinimler
- Python 3.8+
- `yt-dlp` (`pip install yt-dlp`)

## Başlatma
```bash
python3 server.py
```
Sunucu `0.0.0.0:8888` üzerinde çalışır. Nokia N9'un aynı yerel ağda (Wi-Fi) olması gerekir.
